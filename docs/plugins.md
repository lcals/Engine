# 脚本与插件模块

引擎主体与编辑器使用 C++；游戏脚本、编辑器插件和运行插件使用 TypeScript。TypeScript 编译为 JavaScript 后由 [V8](https://v8.dev/) 执行。

参考 Unity 的脚本接口方式：引擎能力由 C++ 实现，并通过稳定的 TypeScript API 供脚本与插件调用。热重载前后保留引擎接口契约、运行中的场景与实体，以及需要延续的脚本数据；更新 TypeScript 逻辑及其与引擎对象的关联。

插件系统与编辑器并列，编辑器可以调用插件。插件分为编辑器插件和运行插件，分别运行在对应宿主中；脚本与插件支持多线程执行，由宿主管理执行与隔离边界。

游戏运行时脚本与运行插件必须支持代码热重载：运行中修改 TypeScript 后，无需重启游戏即可切换到新逻辑，已有运行数据不丢失；若新逻辑无法接续旧状态或更新失败，继续使用上一个有效版本。支持通过增补日志和调整逻辑快速调试。

编辑器代码与插件的热重载目标见[编辑器模块](editor.md)。
