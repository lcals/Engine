# 项目与出包模块

项目包含资源目录 `assets/`、生成缓存目录 `cache/` 和项目设置目录 `settings/`。当前占位项目保存于 `projects/minimal/`，三个目录仅含 `.gitkeep`。编辑器启动时传入 `--project projects/minimal`，宿主先检查根目录及三个必需子目录存在且为目录，检查失败则不创建窗口。当前阶段尚不读取项目设置或资源文件内容。DCC 制作的资源以 USD 格式保存在项目资源目录，资源管线生成的运行时数据放入缓存目录；具体流程见[资源管线](asset-pipeline.md)。

项目是编辑器启动的必需上下文；引擎本身与 Android 运行时均不要求项目目录。`EngineConfig` 只描述引擎配置，`ProjectSystem` 由编辑器宿主持有，`EditorSystem` 借用已初始化的项目。未来的打包资源与脚本入口由游戏宿主配置，不把编辑器项目目录变成底层引擎启动条件。

项目出包规划为由资源管线生成资源清单，再交由平台打包；当前 Android 最小引擎包不加载项目资源。平台专用工程与资源统一存放在 `platforms/<platform>/`，Android 使用 `platforms/android/`；构建与测试命令统一见根 README。

出包以单文件交付为目标，尽量将游戏运行所需内容封装在一个对应平台的可执行文件中。

引擎及游戏的构建产物以尽量小为目标，按项目需求纳入引擎模块、第三方依赖和运行资源。
