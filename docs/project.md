# 项目与出包模块

项目包含资源目录、生成缓存目录和项目设置目录。DCC 制作的资源以 USD 格式保存在项目资源目录，资源管线生成的运行时数据放入缓存目录；具体流程见[资源管线](asset-pipeline.md)。

项目是引擎启动的必需上下文：启动参数必须指定项目，未指定时不启动引擎。启动参数还可以指定项目内的 TypeScript 脚本入口；引擎加载项目后调用该入口。

项目出包通过传入项目名称触发，直接调用 CMake 完成对应项目的构建与打包。出包所需资源清单由[资源管线](asset-pipeline.md)生成。

出包以单文件交付为目标，尽量将游戏运行所需内容封装在一个对应平台的可执行文件中。

引擎及游戏的构建产物以尽量小为目标，按项目需求纳入引擎模块、第三方依赖和运行资源。
