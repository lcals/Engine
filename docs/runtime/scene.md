# 场景模块

场景采用节点模式组织，支持自定义节点类型和节点嵌套。一个 USD 资源中的多个节点分别转换为引擎场景节点，并保留原有的嵌套层级。节点保存可编辑的场景数据，运行时映射为 [flecs](https://www.flecs.dev/flecs/) 实体与组件；场景系统管理节点与运行实体的对应关系及生命周期。

场景空间参数采用高精度表示，以支持大世界；相关运行时模块遵循一致的空间精度约定。

场景与预制体支持保存、加载、实例化和卸载。编辑器操作场景数据，运行时依据场景数据构建实体。

场景与预制体通过稳定资源 ID 引用资源，相关规则见[资源管线](../editor/asset-pipeline.md)。
