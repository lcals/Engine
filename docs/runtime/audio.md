# 运行时音频

[音频系统类图](class-diagrams/audio-system.md) · [音频组件类图](class-diagrams/audio-components.md)

场景通过 `Node + AudioSource` 表达声源，通过 `Node + AudioListener` 表达监听器；位置和朝向来自同一节点的 `Transform` 世界矩阵。组件只保存 FlatBuffers 生成的设置、音频资源引用和瞬时播放请求。`AudioSystem` 借用世界，在主线程处理这些请求并向 SDL3 音频流发布参数；SDL 音频线程按需消费已驻留 PCM，不访问场景对象。

音频源文件由编辑器导入为 `AudioClipData`：交错排列的 F32 PCM，记录采样率、单声道或双声道及帧数。运行时通过统一资源目录和加载接口获得音频，不解码 WAV、不扫描工程，也不依赖编辑器和 MCP。

音量、音调、循环和衰减设置可以在播放中修改；相同 clip 的 `set_settings()` 或 `restore_data()` 保留播放与暂停状态。成功更换 clip 才停止旧播放，失败保留原设置、资源和状态。

`AudioSource::play()` 返回请求是否被接受；缺少音频时返回失败。接受后状态为 `pending`，SDL 设备和流真正就绪后才变为 `playing`。设备初始化或流提交失败时，状态为 `failed`，`AudioSystem::tick()` 返回失败并提供 `last_error()`；不会以静音设备回退伪装播放成功。`playing()` 仅在状态为 `playing` 时为真。

- `play()` 从停止或播放中重新开始；暂停后调用则续播。
- `pause()` 暂停待播放或正在播放的源，保留流内进度；`stop()` 清除请求，下一次音频更新销毁该源的流。
- `play_on_awake` 在每个组件实例首次被音频系统观察为启用时消费一次；当时没有 clip 就不播放。设置 clip、重新启用、播放结束或系统 `clear()` 都不会重复触发。
- 更换 clip 成功后停止原播放；读取失败保留原设置、资源和状态。音量、音调及空间设置变化不重置播放进度。
- 音量和监听器总音量为 `[0, 1]`，音调倍率为 `[0.01, 4]`；距离必须有限，`0 <= min_distance < max_distance`。空 GUID 表示未设置 clip。
- 优先选活动场景中按节点顺序排列的第一个启用监听器；活动场景没有监听器时再查询已发布的常驻场景。空间声源没有有效监听器时静音但仍推进时间；非空间声源不需要监听器。
- 空间声源在最小距离内保持音量，最大距离外静音，中间线性衰减；按监听器世界右方向计算左右声道平衡。双声道空间声源先取均值再定位；非空间双声道保留原声道。

系统按需打开一个 SDL 逻辑输出设备，每个正在播放或暂停的声源拥有独立音频流，并共享拥有不可变 PCM 资源直到流销毁。`SDL_SetAudioStreamGetCallback` 根据设备请求补足输入样本，回调完成声道处理、循环游标和末尾 flush；不读磁盘、不等待 future、不操作 Scene 或 VM，也不创建自有音频线程。音调使用 SDL 频率倍率，音量使用流增益。主线程通过 SDL 流锁发布空间参数与循环设置、读取完成状态，锁内不生成 PCM。Tracy 通过 `Audio.publish` 和 `Audio.feed` 分别记录主线程发布与 SDL 音频线程供数。

主线程暂时没有更新时，已发布的音频仍按设备频率持续播放；自然结束状态在下一次主线程更新同步至组件。暂停单个源只解绑该源，保留流与游标；宿主进入后台调用 `set_paused(true)` 暂停整个输出设备，返回前台恢复，不改写组件播放请求。回调错误仅保存失败标记，主线程下次更新负责报告并释放对应声源。

系统只记录场景 ID、节点 ID、资源修订和播放游标，不跨帧借用节点或组件指针。停用声源或其节点子树在下一次音频更新解除流绑定并保留播放游标，恢复后继续；删除节点及普通场景卸载清理失效源的旧流，常驻源继续保留播放游标；宿主结束玩法或关闭世界前调用 `clear()`，同步销毁全部流和设备。`clear()`、关闭和部分初始化失败均可重复清理。首次播放前不打开设备；最后一个声源自然结束只释放流，保留当前场景的设备，避免截断已经混入硬件输出缓冲的尾音。普通场景切换不主动关闭共享设备；没有已发布场景、显式 `clear()` 或关闭时释放。

自动回归使用 SDL 的 dummy 输出，检查不更新主线程时的一次性音频消费、循环、暂停、停止、换 clip、失败及释放；这不代表真实设备的扬声器或人工听觉验证。系统不涉及录音、麦克风、音频总线、混响或平台专有音频策略。
