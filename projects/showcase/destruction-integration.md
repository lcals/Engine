# 地形与建筑综合联动场

第八个菜单入口为 **Combined destruction laboratory**，资源、玩法与测试统一位于本项目，不借用其他项目的商业素材。原有地形和建筑实验场保持独立。

## 玩法与职责

- 平坦的分块体积地形承托原有塔、墙和柱试件；仍使用已有公开角色和第三人称控制器。
- **Dig foundation** 只挖掉塔下的土，再明确请求破坏组件按地形 Collider 检查支撑；不调用爆破伤害假装地基失效。
- **Blast tower / Blast wall** 提交显式建筑损伤与地形球形挖掘，播放当前位置的爆破与灰尘；成功改地形后重新检查支撑。
- **Fill crater** 可以补回地形，但已经断开的支撑不会自动重接；**Reset all** 才恢复资源初态、建筑连接和角色起点。
- **Overview / Front view / Walk / Respawn** 提供观察、第三人称行走和角色复位。行走仍使用键鼠；触屏可以操作面板按钮，不宣称已提供触屏摇杆。

核心物理只报告接触结果；地形、破坏、特效插件与核心音频系统各司其职。项目脚本决定支撑检测时机、碰撞损伤阈值、冷却、每帧预算和表现播放。没有自动爆破或定时掉块演示。

## 撞击处理

`Physics.GetImpacts()` 的帧号只消费一次，并检查当前破坏组件对两端节点的归属。先收集本帧受击对象，再提交损伤，避免第一次重建碎块后丢失后续事件的节点归属。伤害要求足够的碰前接近速度和估算冲量；同一破坏源有冷却，每帧最多两次损伤，重置间最多 24 次二次损伤。静止接触和新建碎块的轻微碰撞不会无限连锁。

`estimatedImpulse` 是 Jolt 官方碰撞响应估算值，不是求解器实际施加的冲量。它只作为本示例的玩法阈值。声音与特效使用有限节点池，按实际接触点播放；资源绑定由场景或构建根声明，不靠动态字符串隐式打包。

## 自制表现资源

爆破、灰尘使用固定版本 Effekseer 官方 C# 数据模型与导出器制作，只使用现有适配器支持的预定义精灵材质。工具源码在 `scripts/showcase_destruction_effects/`；不手写特效二进制、不改上游检出。所用公开贴图与许可记录于 `assets/effects/source.md`。爆破和碎石声由确定性数学信号合成，没有外部录音采样。

切换镜头只启用一个 AudioListener。返回菜单、重进场景和关闭项目都会清理本模块的 UI 订阅、效果播放、声音及运行时节点；生成碎块仍不写回源场景。

## 验收边界

入口加载后先准备真实地形碰撞和破坏对象，再开启按钮与角色。需要逐项点击验收挖地基、坍塌接触与二次损伤、爆破表现、填土不重接、重置、镜头切换和返回菜单。这里是实心预破碎试件，不等于空心建筑、承重应力、导航更新或土石塌方；没有自动保存综合世界状态。平台运行结果由引擎阶段验证文档记录，不把资源生成或 TypeScript 检查当作设备验收。
