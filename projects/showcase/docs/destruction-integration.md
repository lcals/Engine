# 地形、建筑与火箭综合联动场

第八个菜单入口为 **Combined destruction laboratory**，在同一场景组合重力应力、动态土石、静态导航和连续火箭；原有第六/七地形与建筑实验场保留。本场景新增模型、脚本、资源与测试只属于本示例项目；付费或私有参考代码、资源不纳入版本管理。

## 场景与项目参数

四份参数化盒体预破碎资源分别为塔 **256** 块、墙 **128** 块、柱 **64** 块、悬臂梁 **72** 块，共 **520 个资产片段**。片段仍按 Blast 当前连通组组合成刚体，不是初始就生成 520 个活动刚体。地形为 64×64 米、32 米高的有限体积，项目额外填出细底座和悬挑土帽用于脱离测试；角色继续使用原有模型与第三人称插件。

参数集中在 `assets/scripts/models/destruction_range_config.ts`，引擎不识别这些场景名字或玩法常数：

| 参数 | 当前配置 |
| --- | --- |
| 火箭 | 64 槽固定池；速度 30 m/s；扫掠半径 0.12 m；寿命 5 个模拟秒 |
| 连射 | 2 / 6 / 12 发每秒请求，进入场景默认 6；一次 60 发，可停止；每帧最多新发一枚，不追赶卡顿积压 |
| 建筑损伤 | 半径 5.5 m、伤害 14、显式冲量 45000；位置来自实际飞行扫掠命中 |
| 地形 | 球形挖掘半径 3.8 m；悬空岛最小 8 个样本；每碎块 2 单元分组；密度 250 kg/m³；总活动土石最多 96 |
| 应力 | 普通结构弹性/致命阈值 `1e8 / 2e8`；弱梁 `10 / 20`；500 次求解迭代预算；项目每 0.5 模拟秒显式请求 |
| 表现 | 8 个灰尘槽、6 个爆破槽；独立 Effect + AudioSource；池满只丢可选表现，不追加无限节点 |
| 导航 | 只提交静态 Terrain 的实际网格；0.5 m cell、0.2 m 高度步长、16 cell tile；按 0.25 模拟秒合并并刷新脏区 |

64 槽覆盖最高请求频率 12 发/秒与 5 模拟秒寿命的 60 枚理论在途量，并保留少量余量；这是固定容量配置，不代表达到该实际吞吐。

宿主 `Time.deltaTime` 有 0.1 秒上限，因此请求发射率及模拟节奏不代表墙钟吞吐。同步挖掘、应力、碰撞或导航会造成卡顿，面板另用 `Date.now()` 记录真实墙钟间隔，不通过截断的模拟 dt 隐藏长帧。

## 操作

- **Rocket: tower / wall / ground / earth cap** 从角色发射火箭朝对应区域飞行；**Fire along view** 使用玩家镜头前方作为瞄准方向。弹体从枪口开始逐段执行 `Physics.CastSphere`，遇到真实碰撞才按命中位置爆炸；不会直接在按钮目标点引爆。
- **60-round barrage / Cease fire / Rate: 2 / 6 / 12** 控制固定目标序列的连续射击。停止只取消新发射，在途弹继续飞行和命中；再次开始为新的一轮 60 发。池满时本次尝试计入 blocked，后续按正常间隔重试，没有补发任务队列。
- **Excavate tower** 只挖掉塔下土壤并刷新地基，不调用直接爆破伤害；失去支撑后由 Jolt 下落、实际接触触发有预算的二次损伤。
- **Weak beam / normal** 切换悬臂梁的项目强度，由官方 Blast 重力应力求解决定连接损伤。普通结构使用较高阈值保持初始试件稳定；恢复强度不接回已断连接，Reset 才恢复原始图。
- **Query ground route** 查询静态地形上固定端点间的完整路径；有待更新脏区时先刷新，修改后不继续显示旧路线。移动土石和建筑残骸没有烘焙进此路线，路线显示不代表角色或敌人已经自动跟随。
- **Fill crater** 补回土壤，不重新锚定已断建筑，也不吞掉正在运动的土石。
- **Reset all** 停止连射和日志采样、回收弹体/表现、恢复初始地形并重建项目土帽、清理动态土石、恢复四个建筑图，再刷新支撑和导航、复位角色。它不是读取综合游戏存档。
- **Overview / Front view / Walk / Respawn** 提供固定观察、第三人称行走和角色复位。键鼠控制角色；触屏操作面板，当前没有触屏摇杆。切换镜头只启用一个 AudioListener。

## 联动与失败处理

实际命中后，项目依次提交建筑球形损伤、地形挖掘、悬空土石提取、地基支撑检查、表现和导航脏区；各模块接口仍独立。地形、破坏与特效插件不互相驱动业务，核心也不知道火箭或测试地图。

土石提取以六邻域识别不再连接下/侧边界的负密度区域，按项目尺寸分组；现有 Transvoxel 生成表面，逐单元 Jolt 凸包 compound 产生真实动态 Node + MeshRenderer + Collider + RigidBody。超过剩余碎块预算或准备失败时，本次待转换土石保留在原体积；先前已成功的建筑损伤和挖掘不会假装回滚。报错显示在面板，已有碎块继续运动，后续仍可挖填和 Reset。

笔刷和土石抽离仅重建源地形实际变化范围及梯度法线邻域。碰撞使用稳定的 4 单元叶子和 Jolt 分组树，未变几何共享原形状，一个地形仍是一个 Collider/BodyID；渲染继续合并 Mesh 并完整上传 GPU。Reset、加载及基于完整快照的编辑恢复仍会重建全部块。本项目调用同步接口并等待发布，核心可在共享任务域并行准备，不能将同步返回语义等同于全链路单线程。

导航沿用 Recast `Sample_TileMesh` / Detour。调用者传入全部当前静态几何和覆盖变化的 dirty AABB，只重建相交瓦片及必要边界；本场景发生土石脱离时保守刷新整个地形范围。失败时受影响旧瓦片失效，不允许使用旧路径跨越新坑。暂不导航动态碎块，不做自动场景扫描、AI 代理或避让。

`Physics.GetImpacts()` 每个 frame 只消费一次，先解析受击碎块归属再施伤。速度与冲量门槛、同源冷却、每帧最多 2 次/重置间最多 24 次二次损伤，限制连锁；火箭直接损伤不占该碰撞预算。`estimatedImpulse` 是 Jolt 官方碰前响应估算，不是求解器实际施加冲量。

## 采样与当前性能

每次开始连射会清空本轮帧间隔统计；发射、命中、失手和 blocked 计数在 Reset 之间累计。每约一秒输出 `Rocket range sample` JSON，结束并且在途火箭清空后再输出 `complete: true`。停止发射后同样等待在途火箭结束；Reset 直接停止采样。日志包含请求频率、`actualRate`、发射/命中/飞行/失手/blocked 数、剩余弹数、建筑组/动态组、土石、应力断键、导航状态和墙钟帧间隔。

`actualRate` 来自本轮成功发射次数与发射时间跨度，观察实际达到的发射率；面板是 `Date.now()` 墙钟帧间隔的指数平滑及最大值，**包括限帧等待、同步工作和截图开销**。这不是 CPU/GPU benchmark，不是 P50/P95/P99，也没有扣除后台应用影响。性能结论须结合固定资源版本、操作序列、编译配置、设备和采样方式，不将设定的 12 发/秒当作实测达标。

性能采集使用已固化的 [Tracy 采集与离线分析流程](../../../docs/runtime/performance.md)，保留固定镜头、资源版本和 60 发序列。当前物理与破坏优化包括组增量发布、快照和形状复用、分段地形碰撞及物理姿态同步；完整说明统一见[当前实现](../../../docs/runtime/performance.md#当前实现)。不同分辨率、命中量或物理演化结果不直接换算等工作量加速比。

[最终可信基线](../../../docs/runtime/performance.md#历史单线程基线)记录单次完整地形碰撞更新最大 **0.468999 ms**；Jolt 单步均值 **1.135225 ms**、P95 **1.976267 ms**、最大 **3.280668 ms**。这是 2026-11-01 的单线程历史样本，地形局部更新达到 0.5 ms 门槛，**整个物理模块当时尚未达到 0.5 ms**；不能作为当前并行版本或手机性能结论。其他模块热点只记录，不自动扩大优化范围。

## 原创表现与制作

`dust.efkefc`、`burst.efkefc` 和 `rocket-trail.efkefc` 使用固定 Effekseer 1.80.8 官方 C# 数据模型与 `Core.SaveTo` 导出，保留可编辑数据，只用适配器已支持的预定义 CPU 精灵材质。尾迹的粒子创建时继承位置/旋转，发射器随火箭移动；命中、寿命到期、Reset 和退出停止播放。制作工具见 `projects/showcase/tools/showcase_destruction_effects/`，贴图及许可见 [特效来源](sources/effects.md)。

爆破/碎石声为确定性数学信号合成的原创 48 kHz 单声道 PCM16；音频和效果分别由普通组件播放。模型、材质、声音、效果及邻接 meta 进入统一资源管线；没有自制二进制特效格式、另一套粒子渲染器或隐藏的商业资源。

## 验证记录与边界

已有 Mac Debug/Release 受影响构建与定向回归覆盖物理、角色控制、地形和破坏运行时及编辑器破坏命令；真实 Metal 窗口验证过连射、停火、地基与二次破坏、填土、重置、角色短走、返回及停止清理。功能阶段事实见[验证记录](../../../docs/plugins/runtime/terrain-destruction-feasibility.md)，性能和采集后的清理证据统一见[最终可信基线](../../../docs/runtime/performance.md#历史单线程基线)。Android ARM64 的独立 Graph/ExtStress 探针不能替代正式 APK 场景或实体手机吞吐与发热验证。

当前不含综合世界存档、动态土石/建筑残骸导航、完整空心高楼承重或材料模型。项目仍使用同步操作；引擎已有球形笔刷/建筑损伤的有界异步接口，本场景没有通过它们组织完整异步联动。土石从体积剥离后，旧静态 `TerrainStateData` 保存/恢复明确失败直到 Reset/更换基础资源；不能只保存剩余土壤而悄悄丢掉碎块。
