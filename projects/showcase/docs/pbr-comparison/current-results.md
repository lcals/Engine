# PBR 对照结果

本页保存 2026-11-04 在 macOS Metal 上的受控材质球结果，供渲染修改对照；不代表最新提交或其他平台已通过验收。场景设置见[材质球对照](../pbr-comparison.md)，采集工具见[复现方法](tools.md)。

## 条件与证据

- Release 编辑器，1280×720 原生输出；12 组引擎截图，其中 AO 仅作引擎侧检查，其余 11 组对比 Blender 5.2。
- Blender 线性 EXR 与引擎使用相同曝光 1、Reinhard 和标准 sRGB 编码；未调整材质、曝光或灯光来缩小差异。
- 每球取中心半径 72 像素，MAE 为显示编码 RGB 的平均绝对误差，范围 0–255；球序为从左到右、从上到下。
- 原图、差图、逐球 RMSE/亮度和回执位于忽略目录 `build/material-comparison/current/1793770721339431000/`。bgfx API 167 升级复核保存在 `1793773436458021000/`，该批 PNG 指纹与前批相同。

## 独立验证边界

- 同期 macOS Metal 场景 HDR 回读覆盖直接光、纹理和 IBL 组合，RGB 为 `2.66211 / 1.67676 / 0.98535`，解析参考为 `2.66335 / 1.67708 / 0.98538`。这不等于全部材质和场景的验证。
- IBL 源 mip 修正使用固定高对比 HDR、256 样本、6 面 7 个 mip、126 个 RGB 样点，平均绝对误差 `0.00684`、最大 `0.09212`。该数值仅适用于该输入和采样条件，不能概括摄影 HDR 或持续负载。
- 精确 sRGB 表与更早的 gamma 2.2 截图不能混用；8 位截图逆转换也不能替代浮点 HDR 直接回读。
- 高对比 IBL 的有限采样、SSR 屏幕外缺失与多散射残项、网格及抗锯齿差异仍影响结果。光照辐射单位未独立标定，该组未验证 Windows、Android 或 iOS。

法线与切线对照中的定义差异、数据检查和来源见[法线对照方法](normal-findings.md)。中间修复表格和逐次运行日志由 Git 保存，不维护多份“当前结果”。
