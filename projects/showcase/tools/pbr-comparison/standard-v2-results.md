# PBR 参数对比：standard-v2 历史复测

本页保留早于 SpecGloss、IBL 和法线终止线后续修复的截图及数值；“旧／新”仅比较当时两个阶段。当前状态见[当前结果](current-results.md)。

2026-11-04，以 Release/Metal 编辑器在原相机、光照和材质参数下重拍 12 组，截图原生 1280×720；场景通过 MCP 预览，截图均由 `capture_frame` 返回 `complete`。`*-standard-v2.png` 是当时直接光修复后的图；`*-fixed.png` 是仅含 AO/正交相机修正的中间版；不带后缀的是更早原始基线，三者均保留。

每格统计同一个球内部半径 72 像素，单位为 0–255 的显示编码 RGB；MAE、RMSE 越小只表明这组截图更接近，并不代表物理正确。逐组 JSON、绝对差图和捕获回执在 `build/material-comparison/expanded/results/<组>-standard-v2/` 和 `build/material-comparison/expanded/standard-v2-receipts.json`。

本轮仍非完全同条件：引擎显示变换 Reinhard+gamma 2.2，Blender 为 Standard/sRGB；方向光数值相同但辐射单位未校准；引擎纹理经 UASTC，Blender 使用源 PNG。法线和 UV 组使用同源几何，其余 Blender 参考为原生球。Alpha 是阈值裁切，并非透明混合；镜面 IOR 反解仅在正入射灰度 F0 下对应，第六个关闭直射高光的贴图球没有严格等价参考。ORM AO 无 Blender 同义输入，单列直射测试。
